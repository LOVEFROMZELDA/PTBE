# 200-by-200 Virtual Array Recognition

This directory contains the dataset-generation, training, and test-set inference code for the 200-by-200 virtual array task. The virtual-array dataset is generated from an experimentally measured waveform in `waveform/sample.xlsx`.

The dataset in `dataset.zip` is generated by `dataset_generation.m`; it is synthetic and is not experimentally measured.

Open this directory as the MATLAB current folder before running the commands below.

## Files

- `dataset.zip`: generated virtual-array dataset
- `waveform/sample.xlsx`: experimental waveform used for data generation
- `dataset_generation.m`: regenerates the `dataset/` directory
- `signal_classification.m`: trains the network and saves `NET.mat`
- `CNN_sample.m`: evaluates the pretrained model on the fixed test set
- `hyperparameter_ablation.m` and `Ablation.m`: optional experiments
- `NET.mat`: pretrained model and data split

## Use the Provided Dataset

Create a directory named `dataset/` beside the MATLAB scripts and extract the numbered class directories from `dataset.zip` directly into it. Then run:

```matlab
CNN_sample
```

The script reports the test sample count, overall accuracy, per-class accuracy, and a normalized confusion matrix.

## Regenerate the Dataset and Retrain

```matlab
dataset_generation
signal_classification
CNN_sample
```

Dataset generation and training use the fixed random seed `rng(2026, 'twister')`.

## Retrain with the Provided Dataset

```matlab
signal_classification
CNN_sample
```

Running `signal_classification.m` overwrites `NET.mat` with the newly trained network and `splitInfo`. Run `hyperparameter_ablation.m` or `Ablation.m` only when the optional experiments are needed.
